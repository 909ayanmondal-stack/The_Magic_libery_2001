# The Magic Library 2001

An AI-powered library management system built using Google ADK.

## Features

- Book search and recommendations
- Library assistant agent
- User query handling
- AI-powered interactions
- Modular agent architecture

## Project Structure

```text
The_Magic_libery_2001/
├── cloud_kitchen_ADK_Agent/
├── local_ADK_Agent/
├── waiter_ADK_Agent/
├── requirement.txt
```

## Installation

1. Clone the repository

```bash
git clone https://github.com/909ayanmondal-stack/The_Magic_libery_2001.git
```

2. Install dependencies

```bash
pip install -r requirement.txt
```

3. Create a `.env` file and add your API keys.

## Usage

Run the desired ADK agent and interact with the AI-powered library system.

- Python
